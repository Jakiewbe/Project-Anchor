# Project Anchor 1.5.1

版本：1.5.1；标签：v1.5.1。固定提交、远程CI及源码包身份记录在发布资产release-verification.json，校验值见SHA256SUMS.txt。

## 变化

本版包含1.5.0未正式发布的本轮focus、真实命令凭据、自查、输入过期与持久历史归档；新增真正只读查询、断点任务关联、交付覆盖、按范围验收计算和精简复盘。

## 升级

先统一工具箱版本及各客户端安装，再按项目执行`status`、`migrate --dry-run`、显式`migrate`。schema1/2/3升级至4会备份；有后续修改的迁移不能直接回退。旧工具拒绝schema4，不混用版本。

保留历史批准、任务状态、凭据和原文件。schema3原凭据继续按原范围计算，交付覆盖为undeclared；继续执行、重新结项或作为依赖前，须task revise、声明deliverables、补齐checks并重新批准。无本地文件交付显式填[]，不会由程序猜测历史产物。schema1/2的原legacy限制保留。

保存CURRENT新增--task ID（可重复）或--no-task；其他文档不传。只读查询无需写权限，但状态变化或未完成事务仍直接失败。记录关联一致不证明文字语义。

## 验证与边界

验证报告：[ITERATION_1_5_1_VALIDATION.md](ITERATION_1_5_1_VALIDATION.md)。运行时仍仅依赖Python3.11+标准库；主验收环境Windows，Linux为信息性结果。真实项目仅在本机副本测试，未迁移业务原件。原生测试不证明Hook自动注入、其他宿主或模型长期遵从。
