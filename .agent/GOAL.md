# Project Anchor 项目目标

## 核心目标
交付可独立运行、可通过Git长期维护的文件式智能体项目治理工具箱Project Anchor；当前提供Codex适配，逐步通用化复用同一Python核心和任务账本。

## 项目背景
依据用户 2026-10-08 的完整新项目开发要求，从空目录构建，文件作为长期状态来源。

## 关键约束
Windows 优先，Python 标准库，支持中文和空格路径；开发默认使用隔离配置；本轮用户已明确要求本机全局部署，允许合并安装规则、Skill 和 Hook，不自动推送，不创建分支或工作树；知识入库需要用户确认。

## 非目标
不构建数据库、网页、后台服务、付费 API 或自动多会话合并；不证明模型永远遵守规则，不自动提交业务项目。

## 验收标准
初始化和状态有效，任务及进度安全更新；Hook 官方协议合法；安装保留既有配置；doctor 区分已验证和未验证；测试通过，文档支持独立使用，真实客户端未验证层清楚记录。

新增验收：原生 codex-rules Skill 复用现有 CLI；安全安装/更新；支持自然语言治理；自动化、模拟、真实客户端验证分别记录。

新增部署验收：本机全局规则与 Skill 安装完整；首次实际项目工作默认接入且保留旧状态；真实模型调用单独验收；原生 Hook 审核仍由用户完成，不把未信任或未实测的压缩描述为成功。
