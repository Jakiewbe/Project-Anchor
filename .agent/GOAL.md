# codex-rules v1.0 项目目标

## 核心目标
交付可独立运行、可通过 Git 长期维护的本地 Codex 项目治理工具箱。

## 项目背景
依据用户 2026-10-08 的完整新项目开发要求，从空目录构建，文件作为长期状态来源。

## 关键约束
Windows 优先，Python 标准库，支持中文和空格路径；不修改真实用户配置，不自动推送，不创建分支或工作树；知识入库需要用户确认。

## 非目标
不构建数据库、网页、后台服务、付费 API 或自动多会话合并；不证明模型永远遵守规则，不自动提交业务项目。

## 验收标准
初始化和状态有效，任务及进度安全更新；Hook 官方协议合法；安装保留既有配置；doctor 区分已验证和未验证；测试通过，文档支持独立使用，真实客户端未验证层清楚记录。

## 目标版本
2（用户需求已明确；state.json 记录正式版本）
